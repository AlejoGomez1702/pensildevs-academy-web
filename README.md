# Pensil.Devs Academy

Cursos, videos y documentación de Pensil.Devs, organizados por producto y por servicio. Cada producto tiene documentación funcional y técnica, que se lee ingresando con la cuenta del producto (Pensil.Pos: la misma de pensilpos.com). Angular 22, Tailwind 4 y Vitest.

```
npm install
npm start        # http://localhost:4200 (ingresar usa Pensil.Pos local en :9000)
npm run verify   # lint + pruebas con cobertura + build
```

Reglas de arquitectura, pruebas y estilo: [CLAUDE.md](CLAUDE.md). Specs: [specs/](specs/). Decisiones: [docs/adr/](docs/adr/).

Video introductorio de Pensil.Pos: [tools/video-introduccion/](tools/video-introduccion/README.md).
