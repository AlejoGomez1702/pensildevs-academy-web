# Pensil.Devs Academy

Cursos, videos y documentación de Pensil.Devs, organizados por producto y por servicio. Angular 22, Tailwind 4 y Vitest.

```
npm install
npm start        # http://localhost:4200
npm run verify   # lint + pruebas con cobertura + build
```
